# PESCA GPS PWA v1.3

Test GPS reale con `watchPosition()` e richiesta di alta accuratezza.

Aggiunge:
- latitudine/longitudine
- precisione GPS
- altitudine quando disponibile
- velocità e direzione quando disponibili
- distanza percorsa
- registrazione locale della traccia
- avvio, arresto e azzeramento

Nota: una PWA/browser può avere limitazioni quando è realmente in background o con schermo spento. Per il tracciamento di gara affidabile passeremo alla versione Android/iOS nativa.
